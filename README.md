# Cyberpunk Tactics

A turn-based tactical game combining Cyberpunk RED rules with XCOM-style crew management. Personal project, built in Godot 4.7.2.

- Design: [docs/design-spec.md](docs/design-spec.md)
- Roadmap: [docs/roadmap.md](docs/roadmap.md)
